# ⚡ Energy ETL Pipeline & SQL Analytics (MDMS)

> **Production-style ETL pipeline + SQL analytics engine for smart meter data**
> Simulates an MDMS database with 200 consumers across 6 months, with automated KPI dashboarding

---

## 📋 Overview

This project demonstrates an end-to-end **Extract → Transform → Load** pipeline for smart electricity meter data, modelled on real AMI/MDMS systems used in India's RDSS smart metering infrastructure.
